# 첫 검색 기준값과 무료 자동화 — 2026-10-22

이번 변경은 실제 AI 검색 관측의 입력과 GA4 집계 조회를 줄인다. 검색 노출 또는 매출 증가를 확인했다는 릴리스가 아니다. 소비자용 AI 검색을 무인으로 반복 실행하거나 새 유료 API를 연결하지 않는다.

## 구현

- 검색 관측 JSON을 한 번에 20개, 64 KiB까지 검토하고 저장한다. 기존 계획의 질문, 기간, 반복 번호, 실제 시각을 검증한다. 같은 요청 ID로 재시도하며 부분 실패 전의 성공 기록은 보존한다.
- 변경 후 관측이 없어도 변경 전의 언급과 자사 인용 기준값을 분자와 분모로 표시한다. 미관측, 오류와 AI 답변 미표시를 0으로 바꾸지 않는다.
- 연결된 GA4에서 한 번의 사용자 실행으로 속성과 시간대, 브랜드 도메인의 전체 세션, AI 출처 세션, 페이지 조회수를 가져온다. 속성 조회 1회와 집계 조회 2회이며 AI 모델은 호출하지 않는다.
- 요청 ID 재시도는 저장 결과를 재사용한다. 같은 날짜와 조회 조건은 24시간 재사용한다. 사용자 하루 4회, 전체 40회, 브랜드당 100개와 512 KiB로 제한한다.
- 기존 OAuth 연결을 재사용하고 기존 유입 보고서와 last_synced_at을 덮어쓰지 않는다. 권한 오류가 나면 기준 자료를 만들지 않고 자격 증명을 보존한다.
- GA4 속성 시간대의 어제까지만 가져온다. UTC로 작성한 계획과 기간, 페이지별 전환 정의가 다르므로 전후 성과 비교에 자동 포함하지 않는다. 전환, 주문과 매출은 null이다.
- 백업 V4는 새 기준 자료를 포함한다. V1/V2/V3 복원을 지원하며 격리 복원에서 ID를 재배정하되 집계와 무결성 해시는 보존한다. OAuth 비밀 정보는 내보내지 않는다.

## 실제 검색 관측

2026-10-22 밤 Codex 내부 브라우저의 Perplexity 시크릿 모드에서 질문마다 새 검색을 실행했다. 브랜드명과 첨부파일을 제공하지 않았다. 두 답변 모두 Lumen 언급과 자사 도메인 인용이 없었다. 개선 대상 출처 25개, 비교 대상 출처 10개를 전체 확인했다.

화면에는 ‘검색’ 모드와 ‘Pro 고급 검색 무료 미리 보기’가 표시됐으며 정확한 모델은 미표시다. 계획의 기본 검색 표기만으로 일반 무료 모드와 같다고 가정하지 않으며 이 차이는 각 관측 메모에 남긴다. 시크릿 링크가 만료될 수 있어 화면과 원문을 로컬에 보존했다. 원문은 Git에 넣지 않는다. 답변이 소개한 다른 제품의 가격과 성과는 이번 관측으로 검증한 사실이 아니다.

검색 화면은 사람이 로그인한 브라우저에서 확인했고 입력 파일 정리와 저장을 자동화했다. Lumen 서버에서 소비자용 검색을 무인으로 수집하는 기능은 제공하지 않는다. Gemini Search grounding을 무료라는 이유로 연결하지 않았다. 현재 가격표, 모델별 지원과 검색 결과 보관/활용 조건이 이 분석 저장 용도에 맞는지 별도 확인이 필요하다.

## 판정 범위와 검증

각 질문 1회에서의 미언급과 미인용은 해당 표본의 기준값일 뿐 시장 전체의 0% 노출을 뜻하지 않는다. 변경 후 결과와 전환 계측이 없으므로 개선 효과, 전환율과 매출 기여는 아직 판정하지 않는다. Lumen의 GA4는 동의한 소개 페이지 방문만 계측하며 구매 이벤트는 설치하지 않았다. GA4에서 0을 받더라도 실제 방문이나 매출이 전혀 없었다는 뜻이 아니다.

통합 테스트 224개와 TypeScript 검사, 변경 파일 ESLint가 통과했다. 독립 검토에서 찾은 www 도메인 누락을 수정한 뒤 관련 테스트 12개도 통과했다. 기본 도메인과 www 도메인의 합계이며 다른 하위 도메인은 포함하지 않는다. 실제 저장, GA4 값, 배포 및 복원 결과는 별도 운영 증거 문서에 기록한다. 기존 무료 Gemini 한도와 시간별 수집기, 7일 운영 검증 일정을 유지한다. 이번 작업은 예약 수집을 즉시 실행하거나 재시도하지 않는다.
