# 신규 사용자 흐름 점검과 개선 — 2026-10-20

대상: 랜딩 → 로그인 복귀 → 브랜드 등록 → 질문 추가 → 첫 답변 수집 → 원문 확인. 기존 Lumen 디자인 시스템 안에서 구현했다. 운영 DB, API 키와 분리된 로컬 D1에서 실제 화면과 입력/저장 동작을 점검했다. 로컬 API 제공자 모듈은 고정 응답 또는 고정 오류만 반환하도록 교체했으며 이 모듈은 ignored work/onboarding-preview에만 존재한다. 실제 AI 요청과 신규 운영 데이터는 만들지 않았다.

## 유지한 장점과 범위

샘플/실제 응답 구분, 무료 한도와 사전 예약, 동의 확인, 계정별 데이터 격리, 모델명/수집 시각/원문, 일반 응답의 검색 미지원 안내를 유지했다. 서버 호출, 한도 정책, 스키마, 일정, OAuth 연결과 지표 계산은 변경하지 않았다. 외부 오픈소스의 대규모 설치나 런타임 의존성 추가도 없다.

- 브라우저: 로컬 로그아웃에서 등록 진입과 자동 로그인 복귀, 최소 입력 등록, 잘못된 도메인 수정, 질문 저장 후 수집 설정, 고정 응답의 완료/원문 열기, 고정 오류의 실패 안내.
